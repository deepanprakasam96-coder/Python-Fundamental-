# 📘 Employee & Project Management – Python Data Analysis

## 📌 Overview
This project is a comprehensive data analysis task involving **employee data**, **seniority levels**, and **project performance**.  
The dataset includes three core tables:
- **Employee Data**
- **Seniority Level Data**
- **Project Data**

Using Python and data manipulation libraries, the project simulates real-world data challenges such as cleaning, merging, applying business rules, and transforming datasets.  
Tasks include handling missing values, analyzing project outcomes, and updating employee attributes based on performance.

---

## ⭐ Key Features

### 🔹 1. Data Cleaning & Preprocessing
- Imputed missing project costs using a **running average** calculated through a `for` loop.
- Split the **full name** column into separate **first name** and **last name** columns.
- Standardized and cleaned inconsistent values for better data integrity.

---

### 🔹 2. Data Merging & Aggregation
- Merged Employee, Seniority, and Project data into a **single unified dataframe**.
- Performed data aggregation for end-to-end employee and project analysis.

---

### 🔹 3. Project Bonus Calculation
- Added a **Bonus** column.
- Employees who successfully completed a project received a **5% bonus** based on the project cost.

---

### 🔹 4. Designation Management (Business Logic)
- Reduced the designation level of employees whose projects **failed**.
- Removed records where the updated designation exceeded **level 4**.
- Implemented logical consistency to simulate real-world workforce management.

---

### 🔹 5. Data Transformation
- Added titles (**Mr.** or **Mrs.**) based on gender.
- Dropped the **Gender** column to anonymize the dataset.
- Produced a finalized, clean dataset ready for further analytics.
